A guided product walkthrough

From missing detail to analyst review

  1. Open the case. Use the local launcher's case reference and token. No real payment information.
  2. Try a complete answer. Enter 123456, confirm it, then open the staff workspace.
  3. Review the evidence. Check the original response, format result and conversation. Add a reason before recording the next step.
  4. Explore the safeguards. Create another case and try an invalid code, help request, changed beneficiary or cancellation request.
A format pass is not proof of correctness. Only the saved case record is verified; no payment is approved, released or cancelled.

The default conversation uses guided policy responses. Optional model assistance only supplies wording; backend rules control state changes.
